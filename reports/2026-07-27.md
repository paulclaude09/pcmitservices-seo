# SEO Audit — 2026-07-27

## Executive summary

PCM IT Services still does not appear in the top 10 for any of the nine tracked non-branded local keywords. The biggest blocker remains **server-side HTML**: every URL returns `<title>Hostinger Horizons</title>` before JavaScript runs, which hurts crawlers, social previews, and indexing. Client-side SEO (titles, metas, H1s, LocalBusiness/Service schema) is materially stronger than the July 20 baseline, but it is not reliably visible to Google without fixing Hostinger Horizons settings. Sitemap returned **500** on one automated probe but **200** on five consecutive curl checks—treat as intermittent and keep monitoring.

## Critical issues

- **Universal server-side title `Hostinger Horizons`** on all routes (verified via curl on `/`, `/services/*`, `/contact`). Client-side titles are correct after JS (Playwright), but initial HTML is wrong for SEO/social.
- **Sitemap intermittency:** the XML sitemap returned **500** on one fetch tool; **200** with valid 17-URL XML on five curl attempts same day. Re-test in Google Search Console; if 500 recurs, escalate with Hostinger support.
- **NAP email mismatch:** Rendered site and contact copy use **support@** mailbox; LocalBusiness JSON-LD on homepage uses **info@** mailbox. Align to one primary email everywhere.
- **Indexable utility pages in sitemap:** `quote-builder`, `client-onboarding`, `ai-readiness-assessment`, `it-service-assessment`, `ai-agent-requirements` — thin/no H1 on several; should be **noindex** or removed from sitemap.
