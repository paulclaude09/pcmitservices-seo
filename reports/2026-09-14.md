## Critical issues

1. **Duplicate server-side SEO on all subpages (6th week unresolved)** — 12 tested pages return identical `<title>` ("IT Support Moncton | Managed IT | PCM IT Services", 49 chars), identical meta description (128 chars), and canonical pointing to `/`. Google cannot rank service or location pages until each has unique server-side SEO in Hostinger Page Settings.
2. **Sitemap intermittent 500 error** — Automated fetch returned HTTP 500 at audit start; curl, Googlebot, and Python urllib return HTTP 200. Risk of GSC sitemap warnings and incomplete discovery for some crawlers.
3. **Location pages + computer repair missing from sitemap** — `/it-services-dieppe`, `/it-services-riverview`, and `/services/computer-repair` all return 200 but are not listed in sitemap.xml (18 URLs total; none of these three included).
4. **Utility pages still in sitemap** — `quote-builder`, `client-onboarding`, `ai-agent-requirements`, `ai-readiness-assessment`, `it-service-assessment` dilute crawl budget and may index thin content.
5. **No server-side H1 on any page** — H1 tags are client-rendered only (0 H1 in raw HTML on all 12 tested pages). Google may not consistently index SPA-rendered headings on Horizons sites.
